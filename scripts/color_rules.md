# Правила извлечения цвета по категориям (из Excel Export Products Sheet)

Источник категории: столбец S (Название_группы)
Характеристики: блоки «Название_Характеристики» / «Значение_Характеристики» (с колонки 52)

## Правила (согласовано 2026-07-17)

| Категория | Правило |
|-----------|---------|
| Женские сумочки и клатчи | брать **Цвет** |
| Женские часы | приоритет **Цвет** → иначе **Цвет корпуса** → иначе пусто |
| Корневая группа | **Цвет**, если нет — пропуск (пусто) |
| Мужские часы | приоритет **Цвет** → иначе **Цвет корпуса** → иначе пусто |
| Мужские ремни | **Цвет** |
| Детские игровые фигурки | **Цвет** |
| Женские ремни | **Цвет** |
| Все остальные категории | **Цвет** (единственный вариант) |
